# arqami-fragrance

A responsive perfume e-commerce website built with HTML, CSS and JavaScript, with WhatsApp order integration.

## Live Demo

🌐 [Visit Arqami Fragrance](https://arqami-fragrance.netlify.app)

## Features

* Responsive design for desktop, tablet, and mobile devices
* Luxury perfume-themed UI
* Product showcase
* Separate pages for Home, Products, About, and Contact
* WhatsApp-based ordering system
* Interactive JavaScript functionality
* Custom images and branding
* Mobile-friendly navigation

## Technologies Used

* HTML5
* CSS3
* JavaScript
* WhatsApp Integration

## Website Structure

```text
├── index.html
├── product.html
├── about.html
├── contact.html
├── style.css
├── script.js
└── images/
```

## Purpose

This project was created as a frontend web development project to build a professional online presence for a perfume business and provide customers with a simple way to place orders through WhatsApp.
